Welcome to Django Email Learning Development Sample Service

This is a sample Django service demonstrating the Django Email Learning package, intended for development and testing only.
We use Vite to build the frontend assets of this Django library. During development, ensure the Vite server is running. In a separate shell from your Django server, navigate to the "frontend" folder, install dependencies npm install and run the development server npm run dev.
We are using react for the frontend development, and for UI components, we are using MUI library.

Also make sure that you have run the necessary migrations python manage.py migrate and have a superuser created python manage.py createsuperuser to access the admin interface.

If you encounter any issues while setting up or running the development server, feel free to start a discussion in the GitHub Discussions.

To access the Course Management interface, navigate to /email_learning/platform/courses/.
